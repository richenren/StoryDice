# 故事星球 · StoryDice

面向约 5–8 岁儿童的中文故事创作小游戏，优先支持亲子共玩，也适合孩子独立操作。

## 当前版本

MVP v0.1：Vue 3 + Vite，移动端优先的纯前端应用。

### 已实现
- **故事骰子**：每轮抽取 6 个图案，至少包含人物、地点、事件、物品；其余位置自由组合，类别可重复但同一轮不重复相同图案；可锁定最多 3 个喜欢的图案，再重抽其他图案。
- **扩充素材库**：126 条故事提示，包含 30 个人物、24 个地点、30 个事件、20 个物品、10 个时间和 12 种心情；每条素材都有独立视觉符号，已有重点项目保留手绘 SVG。统一的高质量独立绘本插画将分批替换完善。
- **故事盲盒**：人物、地点、事件、时间、心情五类提示；支持单类重抽和全部重抽。
- **故事开头提示**：随机切换开头，降低孩子开始讲故事的难度。
- **故事小书**：输入标题与故事正文，将作品保存到当前浏览器的 localStorage。
- **我的故事**：浏览、继续编辑、删除已收藏的故事。
- **儿童友好界面**：温暖的绘本配色、原创 SVG 矢量插画、触屏友好的按钮与响应式布局。
- **本地优先**：核心玩法不需要登录、后端或 AI 服务。

### 暂未实现
录音回放、AI 续写、云同步、英语模式、PWA 安装。这些功能不会阻塞当前核心玩法。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

默认开发地址：**http://localhost:5165**。如果 5165 端口已被占用，Vite 会直接报错，不会静默切换端口。

构建生产版本：

```bash
npm run build
npm run preview
```

## 数据与隐私
故事目前只保存在本地浏览器中，不会上传到服务器。清理浏览器站点数据可能导致收藏丢失；跨设备不会自动同步。

## 设计原则
- 玩法优先，避免为了“益智”而把游戏变成考试。
- 图案没有标准答案，鼓励孩子自由解释。
- 使用原创矢量绘制作为第一版素材，不复制参考商品的品牌或专有图案。
- 先验证孩子是否愿意反复玩，再考虑增加 AI、录音等复杂能力。
