# StoryDice 实施计划

## Phase 1 — 可玩原型（当前）
- Vue 3 + Vite 项目骨架。
- 绘本风格首页与模式切换。
- 故事骰子：随机抽取、锁定、重新抽取、故事开头。
- 故事盲盒：五类提示、单项重抽、全部重抽。
- 故事文字收藏：localStorage 保存、查看、删除。
- README 与产品文档。

## Phase 2 — 亲子体验打磨
- 根据实际亲子试玩调整图案词汇、按钮与引导。
- 增加“轮流讲故事”模式和简短玩法卡。
- 增加更多原创矢量图案，确保视觉风格一致。
- 检查触屏、键盘可访问性与低分辨率设备布局。

## Phase 3 — 可选增强
- 故事录音与回放（仅本地保存，明确告知浏览器权限）。
- 可打印图案卡。
- 英语词汇/故事模式。
- PWA 安装能力和更完整的离线缓存。

## 当前技术约束
- 前端静态应用，不需要后端。
- 数据默认仅保存在当前浏览器。
- 不接入 AI，避免额外成本、网络依赖和不必要的儿童数据收集。
