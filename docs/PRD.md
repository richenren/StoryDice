# StoryDice MVP 需求说明

## 1. 产品定位
面向约 5–8 岁儿童的中文故事创作小游戏，帮助孩子从听故事逐步过渡到主动组织和讲述故事。优先服务亲子共玩，也允许孩子独立操作。

## 2. 核心目标
- 让孩子在 1 分钟内理解玩法并开始创作。
- 通过随机图案降低“我不知道讲什么”的启动难度。
- 不评价故事对错，不给语言能力排名，鼓励想象和表达。
- 不依赖登录、网络服务或大模型即可完成核心玩法。

## 3. 核心玩法
### 3.1 故事骰子
- 每次显示 6 个图案，优先保证四个核心元素：人物、地点、事件、物品各至少 1 个。
- 剩余 2 个位置从图案库自由抽取，因此人物、地点、事件、物品、时间、心情等类别可以重复，组合更有变化。
- 同一轮不重复出现完全相同的图案。
- 最多锁定 3 个图案，避免锁定过多导致无法补齐核心元素。
- 每组骰子至少包含 1 个“人物/角色”图案，降低孩子开始编故事的难度。
- 每个图案可以锁定；再次抽取时保留锁定项。
- 支持一键重新抽取未锁定图案。
- 支持显示故事开头提示。
- 提示语强调图案没有标准答案，可以自由解释；不要求全部使用或按固定顺序讲述，允许改变图案含义、增加角色和改编情节。
- 点击“用这些灵感开写”时，将自由创作提示一并加入编辑器，避免孩子误以为必须照模板完成。

### 3.2 故事盲盒
- 从人物、地点、事件、时间、心情五类中分别抽取一个提示。
- 每个类别可以单独重抽。
- 支持重新抽取全部提示。
- 提示组合仅作灵感，不要求全部按固定顺序出现。

### 3.3 故事收藏
- 用户可输入故事标题和文字内容并保存。
- 故事保存在当前浏览器的 localStorage 中。
- 可查看和删除已保存故事。
- 本 MVP 不保存音频，不上传任何数据。

## 4. 体验与视觉
- 中文简体，移动端优先，适配平板与桌面。
- 采用温暖、明亮、统一的儿童绘本风格：奶油色背景、圆角卡片、柔和色块、原创矢量小插画。
- 大按钮、大点击区域、简短文案，避免复杂菜单。
- 视觉图案以项目原创 SVG/矢量绘制为基础，不复制参考商品的品牌或专有素材。

## 5. MVP 不包含
- 登录、云同步、服务端 API。
- AI 自动续写、AI 评分、语音识别或语音合成。
- 复杂积分商城、广告、付费机制。
- 专业学习报告与家长监控。

## 6. 验收标准
- 两种模式均可正常随机抽取。
- 锁定的骰子在重抽时保持不变。
- 盲盒类别可以单独重抽，也可以全部重抽。
- 收藏故事刷新页面后仍存在。
- 删除收藏有明确确认或即时反馈。
- 375px 手机宽度下不出现横向溢出，主要操作可触控。
- npm run build 成功。


## 7. 第一批素材库规模
当前素材数据第一批扩充为 126 个条目：
- 人物：30
- 地点：24
- 事件：30
- 物品：20
- 时间：10
- 心情：12

新增内容以日常、探索、奇幻、科幻和幽默情节为主，采用适合儿童理解且容易联想的短语。素材数据已扩充；新增角色和元素的专属插画仍需后续逐步完善，避免把“素材已入库”误认为“每个素材都有独立成品插画”。


## 8. 素材视觉映射
- 126 条素材数据均包含视觉符号字段，确保新增条目不会全部落入同一个通用表情图形。
- 原有手绘 SVG 继续用于已有重点角色与物品；其余新增条目先使用可识别的视觉符号作为过渡。
- 过渡符号不等同于最终原创绘本插画。后续按人物、地点、事件、物品分批制作独立插画文件，并通过稳定的素材 ID 映射接入，避免依赖海报截图裁切。
